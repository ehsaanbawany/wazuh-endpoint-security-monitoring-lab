# Endpoint Security & Monitoring Report

## Objective
Deploy Wazuh EDR to monitor Windows endpoints using Sysmon, File Integrity Monitoring (FIM), and threat intelligence.

## Environment
- Wazuh Server
- Wazuh Agent
- Windows 11
- Sysmon
- MalwareBazaar

## Tasks Performed

### 1. Wazuh Deployment
Successfully deployed the Wazuh server and connected the Windows agent.

### 2. Sysmon Monitoring
Installed Sysmon and verified that Windows Sysmon logs were collected in Wazuh.

### 3. File Integrity Monitoring
Verified Syscheck events and monitored file integrity changes.

### 4. Alert Monitoring
Reviewed alert severity levels and analyzed High Severity alerts generated by Sysmon.

### 5. Threat Intelligence
Collected SHA256 hashes from Sysmon events and searched them in MalwareBazaar for threat intelligence validation. No public match was found for the tested hashes.

## Conclusion
The Endpoint Detection and Response (EDR) environment was successfully deployed using Wazuh. Sysmon logs, File Integrity Monitoring, and security alerts were successfully monitored. MalwareBazaar was used as an external threat intelligence source to validate file hashes.
