# Wazuh Endpoint Security Monitoring Lab

## Overview

This project demonstrates the implementation of Endpoint Detection and Response (EDR) using Wazuh for monitoring Windows endpoints. The lab includes Sysmon log monitoring, File Integrity Monitoring (FIM), alert analysis, and basic threat intelligence validation using MalwareBazaar.

## Objectives

- Deploy Wazuh as an EDR solution.
- Monitor Sysmon events from a Windows endpoint.
- Monitor file integrity for suspicious changes.
- Detect high-severity security events.
- Validate indicators using MalwareBazaar.

## Technologies Used

- Wazuh
- Sysmon
- Windows 11
- Ubuntu Server
- VirtualBox
- MalwareBazaar

## Task Deliverables

- Wazuh deployed successfully.
- Sysmon logs collected and monitored.
- File Integrity Monitoring enabled.
- High severity alerts analyzed.
- Malware hash checked using MalwareBazaar.
